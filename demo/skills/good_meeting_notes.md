# Meeting notes

Take the notes the user pastes and produce:

1. A three-sentence summary.
2. A list of decisions that were made.
3. Action items, each with an owner and a due date if one was mentioned.

Keep the user's wording where possible. If an owner or date is unclear, say so instead of guessing.
